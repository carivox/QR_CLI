# 📱 QR-Code Generator CLI

Eine einfache und schnelle Konsolenanwendung (CLI) in Python, die aus eingegebenen Links/URLs automatisch QR-Codes generiert und als `.png`-Datei direkt in deinem **Downloads-Ordner** speichert.

---

## 🌟 Features

- 🔗 **Automatische Dateibenennung:** Der Dateiname wird sauber aus der eingegebenen URL generiert (inkl. Bereinigung von Sonderzeichen).
- 📁 **Downloads-Integration:** Speichert das generierte Bild automatisch im Standard-Downloads-Pfad deines Systems (Windows, macOS, Linux).
- 🛠️ **Robuste Eingabeverarbeitung:** Verhindert ungültige Dateinamen und begrenzt die Namenslänge automatisch.
- ⚡ **Schnell & Schlank:** Ein Befehl, Link einfügen, fertig.
